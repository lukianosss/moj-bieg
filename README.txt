MÓJ BIEG 1.0

1. Utwórz nowe publiczne repozytorium GitHub o nazwie moj-bieg.
2. Prześlij index.html do głównego katalogu repozytorium.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Otwórz https://TWOJ-LOGIN.github.io/moj-bieg/ w Safari.
5. Udostępnij > Dodaj do ekranu początkowego.

Import: Garmin Connect w przeglądarce > wybrana aktywność > eksport TCX lub GPX.
CSV: nagłówki date,distance_km,duration_sec,avg_hr,name (pierwsze 3 wymagane).
FIT nie jest jeszcze obsługiwany. Automatyczna synchronizacja Garmin nie jest dostępna.

Dane przechowywane są lokalnie na każdym urządzeniu, bez synchronizacji.
Rób kopię JSON w aplikacji, żeby nie utracić historii przy czyszczeniu Safari.
Aplikacja nie potrzebuje żadnych dodatkowych kont poza GitHubem do publikacji.
