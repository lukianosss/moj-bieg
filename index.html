Garmin — synchronizacja prywatna

Dane są pobierane przez GitHub Actions i publikowane wyłącznie jako zaszyfrowany plik. Hasło odszyfrowuje dane tylko na Twoim urządzeniu. Nie wpisuj tu klucza Garmin API.

Wygodne, ale mniej bezpieczne: zapamiętane hasło jest zapisane w pamięci tej przeglądarki i może być odczytane przez skrypty działające na tej stronie. Używaj tylko na własnym urządzeniu.

Uruchom synchronizację ↗

Wpisz hasło i pobierz dane. Aby pobrać świeże dane z Garmina, uruchom workflow w GitHub Actions, poczekaj na zakończenie, a potem kliknij „Pobierz aktualne dane”.

Hasło jest zapisywane lokalnie tylko po zaznaczeniu opcji. Jeśli pamięć Safari zostanie wyczyszczona, trzeba wpisać je ponownie. Dane z GitHub Actions aktualizują się okresowo; otwarcie aplikacji odświeża już opublikowany plik, ale nie uruchamia nowego zadania na GitHubie.
